# Análise e Limpeza de Dados — Diamonds (Seaborn)

Exercício de faculdade (Sistemas de Informação) de limpeza e análise exploratória do dataset público `diamonds` (Seaborn). O script em Python trata os dados brutos, gera `diamonds_dados_limpos.csv` e um relatório em HTML com gráficos sobre preço, corte, cor e qualidade das pedras.

## Stack

- Python, pandas, seaborn/matplotlib

## Conteúdo

- `relatorio_diamantes.py` — script de limpeza e análise
- `diamonds.csv` / `diamonds_dados_limpos.csv` — dataset original e tratado
- `relatorio_final_diamantes.html` — relatório gerado
- `assets/` — gráficos exportados

Trabalho de faculdade — Análise de Dados.
